# Lady Porsh Cosmetics

Lady Porsh Cosmetics is a private, brand-owned storefront and digital experience for a premium cosmetics brand. This project is built to showcase beauty products, elevate the brand identity, and provide a modern online shopping experience for customers seeking skincare, makeup, and luxury beauty essentials.

This repository is proprietary and confidential. It is not an open-source project and must not be copied, redistributed, republished, or reused without the explicit written permission of the brand owner.

## Overview

Lady Porsh Cosmetics is designed to represent a premium beauty brand with a clean, elegant, and conversion-focused storefront. The experience combines product discovery, shopping cart interactions, and a polished visual identity built for cosmetics and skincare retail.

## Brand Focus

- Premium beauty and skincare products
- Minimal, elegant visual design
- Product-focused storefront experience
- Mobile-first responsive shopping experience
- A luxury cosmetics brand identity

## Technologies

- Next.js
- TypeScript
- Tailwind CSS
- Redux
- Framer Motion
- ShadCN UI

## Project Status
